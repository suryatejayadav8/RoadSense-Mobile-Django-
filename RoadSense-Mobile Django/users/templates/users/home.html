ROADSENSE-MOBILE

A Smartphone-Based ML Framework for Real-Time Road Surface Detection

RoadSense-Mobile is an intelligent road monitoring platform that uses smartphone sensors and machine learning technologies to automatically analyze road surface conditions in real time.

The system can identify smooth roads, rough roads, potholes and speed breakers by analyzing vibration, acceleration and motion information collected from smartphone sensors.
